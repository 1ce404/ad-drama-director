# 资产图规范

第4步读第 1 节定画风；第5步读第 2–5 节出资产图。资产图就是这支片子的演员、片场和道具：喂给视频模型的参考图越干净，每一段里的人和物就越一致。

## 目录

1. 画风
2. 角色
3. 场景
4. 产品与道具
5. 资产清单与检查

## 1. 画风

- 每套画风方案写清：美术方向（真人写实、3D 国漫、2D 动漫等）、色调、光线、材质、镜头质感，以及它适合这支片子的理由。
- 画风样张与分镜无关，只用来比较色调、光线和材质；不复现任何正式镜头的构图或动作。

## 2. 角色

先出单张定妆图，用户确认长相后再出身份板。

定妆图：

- 全身、正面、白色或米白色背景，双手自然下垂，不拿东西，不做表情。
- 一定写鞋子，否则容易出半身图。
- 写清年龄、身高、体型、脸型、发型、服装，与时代背景对得上。
- 身上固定的特征写清位置，例如“左眉上方一道浅疤”。
- 成年角色约 8 头身；反派也不要丑得太极端。
- 用 AI 设计的形象，不用真人或明星照片作参考。
- 产品功效相关的部位（例如洗护产品的头发、护肤产品的皮肤）如果在剧情里有“使用前”和“使用后”两种状态，各出一张定妆图，其它保持一致。

身份板提示词：

```text
参考这张人物图，做一张 16:9 的角色身份板。白色或米白色背景，没有环境、道具、水印。
- 中间偏左放一张大的正面全身像；周围留出间距，放背面、侧面全身，再放 3 个表情特写。
- 所有图互相不重叠，脸、手、脚都不能被裁掉。
- 所有角度保持同一张脸、同一个发型、同一套衣服、同样的身体比例。
- 风格干净简约，像动画工作室的角色设定页，不是海报。
```

群众演员不单独设计。

## 3. 场景

- 与角色使用同一种画风。

## 4. 产品与道具

- 纯白底，没有背景，没有人。
- 产品需要以特殊方式出现时（例如创意中插的光效、系统发放、古风场景里的摆放），另出一张“产品在场景里”的参考图，并请用户确认标识是否准确。
- 关键道具各出一张，规则同上。

出图后逐张放大检查：

- 每个主角的身份板几个角度是不是同一张脸、同一套衣服？
- 产品和道具有没有错字或乱码？
- 画风、色调与已确认的方案一致吗？
- 缩小到手机屏幕大小看一遍，主体是否清楚？

改图时只改指出的问题，其余保持不变。新版本另存，不覆盖旧文件。
