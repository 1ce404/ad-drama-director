# 创意来源

本文件供第2步生成创意方向时读取。玩法和题材都是起点，不是限制：可以单用、组合，也可以完全跳出。

## 目录

1. 好创意的硬标准
2. 产品作用与删除测试
3. 创意玩法
4. 短剧题材
5. 按产品价值找方向
6. 常见失败模式

## 1. 好创意的硬标准

每个方向在交给用户前，逐条自查：

- 开场钩子：前 3 秒出现异常、冲突、悬念或反常画面，观众不看下去就不知道发生了什么。最抓眼球的画面放在最前面。
- 一句话主题：能用一句话说清这支片子想让观众记住什么。
- 一个主冲突：60 秒以内只讲一个冲突、一个反转。片长更短时合并能用同一画面讲清的事件。
- 产品不可删：通过第 2 节的删除测试。
- 卖点看得见：用户给的卖点尽量变成画面，而不是台词。
- AI 拍得出来：避开人物交叉、手里拿小物件做精细动作、画面里的文字、镜子和倒影、一个镜头里换光、一个人连做三个动作、俯拍看不到脸、配角太多。
- 收口闭环：结尾回应开场的钩子。

## 2. 产品作用与删除测试

删除测试：把产品从故事里拿掉。故事还能讲通，说明产品是贴上去的，重想。

产品可以承担的作用：

| 作用 | 含义 |
| --- | --- |
| 破局工具 | 产品的真实功能帮人物完成关键动作 |
| 关键证物 | 产品的外形、使用痕迹或使用效果完成证据反转 |
| 关系证物 | 产品证明人物的真实动机、关心或误会来源 |
| 身份线索 | 产品暴露人物的职业、习惯或真实身份 |
| 规则核心 | 在系统、游戏、世界观设定里，产品就是规则本身或通关条件 |
| 冲突源头 | 产品的使用或缺失直接引发冲突 |
| 状态触发 | 人物使用产品后作出决定或进入最终行动；不能写成神奇变身 |

产品的能力不得超出用户给出的真实卖点。

## 3. 创意玩法

玩法是讲故事的形式，可以套在任何题材上。

| 玩法 | 怎么玩 | 产品常见位置 |
| --- | --- | --- |
| 系统/游戏 | 主角被系统绑定，属性数值、任务、奖励推动剧情 | 任务道具；卖点对应属性回升 |
| 弹幕/破第四面墙 | 角色看见观众的弹幕或对镜头说话 | 弹幕说出痛点和卖点 |
| 反套路 | 观众以为会这样发展，结果完全相反 | 反转的原因 |
| 戏中戏 | 片场、直播间、舞台，戏里戏外两层 | 戏外的真实需求 |
| 拟人化 | 头屑、油脂、疲劳、问题本身变成角色 | 克制问题角色的力量 |
| 微观奇观 | 进入头皮、皮肤、机器内部，把卖点拍成场面 | 场面里的主角 |
| 倒叙悬念 | 先给结果，再回答“怎么会这样” | 谜底 |
| 时间循环 | 同一天反复重来，每次改一个变量 | 唯一有效的变量 |
| 身份互换 | 两人或两个时代互换处境 | 暴露差异的物品 |
| 规则怪谈 | 一个奇怪的规则支配全场 | 遵守或破解规则的关键 |
| 伪纪录/采访 | 用纪录片、新闻、街访的形式讲荒诞故事 | 被调查的对象 |
| 创意中插 | 剧情主线里插一段与剧情相关的广告式展示 | 中插主角；剧情要为中插铺垫 |

古装、仙侠、年代题材里出现现代包装产品时，用创意中插、系统发放、穿越带来等方式交代，并在故事里写明。

## 4. 短剧题材

题材是故事发生的世界和人物关系，可与玩法组合，例如“古装 + 系统”。下表只是常见选项，用户自定义的题材直接采用并保留原称呼。

| 编号 | 题材 | 典型内容 | 适合承载的产品价值 |
|---|---|---|---|
| 1 | 职场逆袭 | 竞争、救场、成果归属、职业选择 | 效率、能力、专业状态、形象管理 |
| 2 | 甜宠恋爱 | 相遇、误会、试探、关系确认 | 情绪价值、约会体验、礼赠与形象表达 |

| 4 | 豪门总裁 | 身份质疑、宴会冲突、继承与阶层误判 | 品质感、得体形象、身份与能力证明 |

## 5. 按产品价值找方向

先判断产品主要解决的是形象、效率、关系、学习、家庭生活、风险、身份表达还是行动支持，再选最能把这种价值拍成画面的玩法和题材。

| 产品类型 | 常用玩法 | 常用题材 |
|---|---|---|
| 护肤、彩妆、个护、美发 | 系统/游戏、拟人化、微观奇观、反套路 | 职场逆袭、甜宠恋爱、豪门总裁、大女主/大男主、喜剧日常 |
| 服饰、鞋包、首饰、配饰 | 身份互换、反套路、戏中戏 | 甜宠恋爱、闪婚离婚、豪门总裁、真假身份、古装宅斗 |
| 食品、饮料、滋补、礼品 | 时间循环、伪纪录、反套路 | 甜宠恋爱、家庭伦理、萌宝亲子、乡村创业、中老年情感 |
| 母婴、儿童用品、玩具 | 弹幕/破第四面墙、身份互换 | 家庭伦理、萌宝亲子、青春校园 |
| 教育、课程、学习工具 | 系统/游戏、时间循环 | 职场逆袭、萌宝亲子、青春校园、热血竞技 |
| 数码、家电、效率工具 | 时间循环、倒叙悬念、规则怪谈 | 职场逆袭、真假身份、神豪商战、悬疑反转 |
| 家居、清洁、收纳、日用品 | 拟人化、微观奇观、伪纪录 | 家庭伦理、悬疑反转、喜剧日常、中老年情感 |
| 运动、户外、健身用品 | 系统/游戏、时间循环 | 青春校园、热血竞技、战神归来、乡村创业 |
| 珠宝、收藏、文玩、工艺品 | 倒叙悬念、身份互换 | 豪门总裁、古装宅斗、权谋探案、医武鉴宝 |
| 软件、企业服务 | 规则怪谈、时间循环 | 职场逆袭、神豪商战、普法反诈 |
| 适老用品、健康生活用品 | 伪纪录、身份互换 | 家庭伦理、普法反诈、中老年情感 |
| 地方特产、农产品、传统手作 | 伪纪录、穿越 | 家庭伦理、古装宅斗、乡村创业、中老年情感 |

涉及医疗、教育、投资、法律或未成年人时，只根据真实使用场景出方向，不以夸张结果作为卖点。

## 6. 常见失败模式

- 3 个方向是同一结构换背景，例如都是“形象差被嘲笑→用产品→打脸”。
- 卖点只在结尾被念出来，前面的剧情与产品无关。
- 钩子在第 5 秒以后才出现，或开场是平铺直叙的日常。
- 一个 60 秒的片子塞进两条主线或多次反转。
- 反转靠突然出现的救场人物，或没有铺垫的新信息。
- 产品被写成能治病、变身、改变命运的神物。
