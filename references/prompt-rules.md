## 1. 写给镜头的剧本

- 只写镜头拍得到的东西。不写“他心里很难过”，写“他低下头，手指攥紧衣角”。心理活动改成动作、表情或内心独白。
- 每个转折分三段写：问题 → 主角怎么解决 → 旁人什么反应。旁人反应要有先后，不能几个人同一秒做同一个动作；细节要像真人，比如吃惊时身体往后缩。
- 每个转折按现实追问一遍：为什么会这样？东西从哪来？够得着吗？现实里会这样吗？玩法本身不讲现实逻辑时，也要守住它自己的规则。
- 声音分类型标注：`说`（当面开口）、`内心独白`、`画外音`（人不在画面里，声音还在）、`系统音`、`旁白`、`音效`。不分开写，模型会让角色张嘴念心里话。
- 台词按每 10 个字约 2 秒估算，听的人的反应留 1 秒左右。每镜通常不超过两位说话人，避免交叉对话。
- 只在用户提供固定口播时逐字引用。不编造卖点，不为适应镜头擅改固定口播。
- 用户要求画面里没有字幕或文字时，系统面板、弹幕、数值等信息改用声音、光效、颜色或图形表达，不出现可读文字。

## 2. 分镜设计

- 每镜换角度。全片平视正面最多两次，其余用俯拍、仰拍、背后、过肩、透过前景拍。不要连续三镜用同一种景别，全身、半身、特写交替使用。
- 每镜写清“什么在动”：摄影机、焦点、光线、前景飘过的东西或人物的小动作，至少一样。该静的地方静，形成对比。
- 运镜要有理由：跟着人或物走、慢慢推近给特写、从近处拉远揭示环境。说台词时镜头尽量固定。
- 构图：人物的头或眼睛落在画面左右约 38% 或 62% 的位置，不放正中间；9:16 竖屏注意上下留出字幕和平台界面的安全区。
- 每一秒截图都要好看。最抓眼球的画面放在开头。
- 产品露出镜头写清：产品在画面哪里、朝哪个方向、标识是否正对镜头、谁的手怎么拿。
- 镜头之间用动作、视线、遮挡或光线变化衔接。换场景或跳时间时必须切。
- 剪辑点：换人说话就切；情绪每变一次给一个镜头；大动作拆成准备、执行、结果。

## 3. 逐镜时间轴

- 镜头数量和每镜时长由故事决定，不按等长时间格切分。
- 第一镜从 0 秒开始；上一镜结束时刻等于下一镜开始时刻；最后一镜止于目标时长。逐镜核对区间为正、连续、无重叠，总和与目标一致。
- 常用时长：远景、全景 3–4 秒；中景、近景、特写 2–3 秒；反应镜头约 1 秒；高潮 3–5 秒；单镜一般不超过 10 秒。
- 动作、停顿和台词必须在分配的时长内完成。确认后原样沿用镜头数和时间；发现冲突时回到分镜，请用户确认修改。

## 4. 生成段与生成方式

### 4.1 划分生成段

- 按目标模型的单段时长上限，把连续的 2–4 个镜头合成一段，一般 5–15 秒。分段时保留已确认的切点，不擅自改成模型的预设时长。
- 一段只讲一件事：一个动作、一次情绪转折或一句关键台词。不同场景、不同时间必须分段。
- 每段的开头状态接上一段的结尾，不重复上一段已完成的动作。

### 4.2 选生成方式

| 方式 | 适合 | 准备 | 风险 |
| --- | --- | --- | --- |
| 多参考（默认） | 人物表演、对白、走位，构图不需要精确控制 | 资产图 | 构图由模型决定；产品标识可能变形 |
| 首帧 | 构图必须准确：开场钩子、产品露出、关键证据 | 一张首帧 | 多画一张图 |
| 首尾帧 | 前后状态必须对上：变化过程、与下一段严格衔接 | 首帧与尾帧 | 两帧必须对齐，否则画面会漂移 |

多参考：

- 参考图逐张写明用途：`@图片1 = 沈砚的长相`、`@图片2 = 偏院卧房`、`@图片3 = 产品`。
- 一段只放一张场景图。
- 参考图张数以目标模型的上限为准，最重要的放前面。

首帧与首尾帧：

- 先写每帧画什么，再画。
- 动作要用到的东西，首帧里必须已经有；旁人的反应要在首帧里摆好位置。
- 先画内容最多的一帧（通常是尾帧），在它上面改出另一帧，保证机位和构图一致。
- 要推近的镜头，尾帧可以从首帧裁切放大；首尾帧完全相同等于镜头不动。
- 同一地点、同一机位的镜头，在上一张图上局部修改，不重新画。
- 提交前检查画幅与目标比例一致，首尾帧尺寸相同。

## 5. 逐段视频提示词

每段按下面的格式写。替换所有占位符，不保留模板说明。

```text
【素材段落 X｜镜头 A–B｜X 秒｜生成方式：多参考 / 首帧 / 首尾帧】
【参考】@图片1 = ……；@图片2 = ……；（首帧 / 尾帧：……）
【画风】一句话画风，与已确认画风和参考图完全一致。
【站位】谁在画面左、谁在右，门在哪边，摄影机在哪一侧，道具在谁手里、朝哪个方向。
【镜头】景别，机位，运镜；不动就写“固定机位，不推不拉不摇”。
【光影】光从哪边来、软硬、冷暖、明暗；同一场戏每段相同。
【人物】每个人的长相、发型、服装、固定道具，每段原样复制同一句。
【逐秒】
0–X 秒：谁做什么，表情怎么变，手放在哪、不碰什么，朝画面哪边走。
……
【声音】某某说：「……」（语气）；某某内心独白：「……」；系统音：「……」；音效：只写看得见原因的声音。每个说话角色附一句固定声音描述（年龄、音色、语速），每段原样复制。
【约束】画面里一直只有这几个人和这些东西，脸和身形全程不变。台词一字不改。没有字幕、文字、水印。
```

- 带货段落写清产品出现的时刻、位置、朝向和标识露出方式；未安排露出的段落不突出产品名称和标识。
- 产品外形、包装颜色、尺寸、标识位置和使用方式在所有段落中保持一致；古风、仙侠、年代题材只用已确认的露出方式（例如创意中插），不新增包装文字。
- 背景音乐建议后期统一加。用户要求片段自带音乐时，再在【声音】里写音乐情绪。

## 6. 模型常见错误与写法

| 容易出的错 | 写法 |
| --- | --- |
| 一群人同时做同一个动作 | 写清先后：“甲先……一两秒后乙才……”；首帧里也不摆同一个姿势 |
| 本该外力做的事，人自己动手做了 | 写清原因，再写“两只手从头到尾不碰……” |
| 物体长出眼睛和嘴 | 不写“卡通”，写具体材质和纹理，只写它怎么移动 |
| 人往反方向走 | 按画面写方向：“朝画面左边走” |
| 一句话有歧义 | 写具体位置：“左上角窗口里”，并写清其他位置的状态 |
| 物品数量变了 | 直接写数量：“只有一瓶” |
| 否定句没用 | 改成正面说法：“画面里一直只有首帧这几个人” |
| 模型联想道具用法 | 不想要的用法就别让道具出现在有动作的镜头里 |
| 东西凭空出现 | 只用首帧或参考图里已有的东西 |
| 东西突然飞走或瞬移 | 写清它怎么动 |
| 小物件拍着拍着消失 | 首帧和尾帧都画上，或放进参考图 |
| 一个镜头动作太多就乱 | 每段只写一两个主要动作 |
| 角色张嘴念心里话 | 声音标为内心独白或画外音，并写“人物不开口” |
| 同一角色声音前后不一 | 固定声音描述，或用第一段满意的声音作参考 |
| 长台词画面发死 | 中途切听的人的反应，台词改为画外音 |
| 产品标识变形 | 产品露出段用首帧锁构图；后期补产品定格 |

## 7. 整片提示词模板

用户只要一段整片提示词（例如交给即梦一次生成）时使用。逐镜时间段按已确认分镜重复。

```text
【视频规格】
[总时长]秒，[画幅]，[语言]微短剧，[题材与画风]。

【整体画质与美术风格】
[清晰度、美术方向、材质细节、人物肤质和成片质感。]

【光影与色调】
[整体光影与色调；有变化时写明哪一镜变成什么色调。]

【运镜与转场的整体要求】
[与分镜匹配的运镜和转场方式。]

【声音规范】
[人声、环境声、音乐和需要的留白。]

【植入要求】
[仅带货片保留：产品在哪几镜如何参与剧情、何时露出标识；有固定口播时写明位置和原文。]

【整体生成质量要求】
[人物、场景、道具和产品连续一致，避免穿帮、换脸、错手、穿模、物品失真和动作断裂。]

[起点]-[终点]秒｜[四字小标题]・[四字小标题]
[画面、运镜、动作、台词、环境音和背景音乐。]【光影色调：[本镜色调]｜画面风格：[本镜风格]】

【硬性执行规则】
总时长[总时长]秒，遵循以上镜头顺序和起止时间。动作和对白须在对应镜头内完成，画面连续。沿用已确认的产品外观；固定口播逐字沿用。

【负面提示词】
[通用项、题材针对项、带货禁用项和用户禁止内容。]
```

负面提示词通用项：

```text
不要字幕，不要 UI 标识，不要卡通化夸张特效，不要多余闲杂人物，不要浮夸夸张的肢体动作，不要面部崩坏变形，不要物品形态失真，不要多人同框复杂互动。
```

用户明确要求某元素时（例如系统光幕），去掉与之冲突的通用项。

| 题材 | 针对性禁用内容 |
| --- | --- |
| 都市职场 | 不要古装或超自然能力，不要无因果升职致富，不要复杂会议群戏 |
| 豪门身份 | 不要靠价格证明人物价值，不要新增家族成员，不要无铺垫改变身份 |
| 重生穿越 | 不要多时间线反复切换，不要两个相同主角，不要复杂时空特效 |
| 古装权谋 | 不要现代建筑、服装或电子设备（已确认的产品露出除外），不要虚构朝代文字，不要大规模群戏 |
| 仙侠玄幻 | 不要游戏界面，不要法术遮挡人物和产品，不要把产品表现成治病复活的神物 |
| 情感家庭 | 不要无铺垫暴力羞辱，不要用产品替代沟通，不要突然增加亲属 |
| 悬疑反转 | 不要血腥畸变，不要凭空出现证据，不要虚构监控或鉴定功能 |
| 青春成长 | 不要危险校园冲突，不要成人化权谋，不要生成校名、校徽或成绩保证 |
| 年代创业 | 不要时代错位物件，不要凭空暴富，不要虚构年代标语 |
| 热血传奇 | 不要群体打斗、爆炸或危险特技，不要复杂赛制和多人调度 |

带货禁用项：未安排露出的镜头不突出产品名称或品牌标识。
