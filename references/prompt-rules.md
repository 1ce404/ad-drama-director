# 微短剧视频提示词规范

第4步用本文件编排文字分镜，第5步用它编译最终提示词。提示词只复现已确认的故事和分镜。出图权限以 [技能入口的出图门槛](../SKILL.md#出图门槛) 为准。

## 1. 模式与通用规则

剧情包含产品使用、品牌揭晓或转化动作时，采用带货模式；纯剧情省略植入要求和带货负面项。不要向用户说明内部模式判断。

- 沿用用户给定且随故事确认的总时长。画幅和语言按用户要求；未指定时用 9:16 竖屏和中文。
- 逐镜融合画面、运镜、动作、台词、环境音和背景音乐。每镜末尾标明光影色调和画面风格。
- 对白保持简短，通常每镜不超过两位说话人，避免交叉对话。按正常语速给台词和必要停顿留足时间。
- 按已确认的镜号安排产品介入、品牌露出和固定口播。优先让产品自然参与故事，再以剧情允许的方式收口。情节或用户要求需要更早露出时，按已确认的分镜执行。
- 只在用户提供并确认了固定口播时逐字引用。不要编造卖点或为适应镜头擅改固定口播。
- 最终只输出提示词本身，不附前言、说明、备注或核对结果。

## 2. 最终模块顺序

1. `【视频规格】`
2. `【整体画质与美术风格】`
3. `【光影与色调】`
4. `【运镜与转场的整体要求】`
5. `【声音规范】`
6. `【植入要求】`，仅带货模式
7. `【整体生成质量要求】`
8. 逐镜时间段，按已确认分镜重复
9. `【硬性执行规则】`
10. `【负面提示词】`

## 3. 逐镜时间轴

先确定每个动作或信息需要何种景别和观看时间，再确定切点。场景或视角变化、关键动作结束、需要看清证据或人物反应时，可以切镜。能由同一画面讲清的剧情点可合并。片长短时优先保留建立冲突和完成反转所需的镜头，给关键对白、动作和产品细节留出足够时长。

- 镜头数量和每镜时长由故事决定。不要把剧情节拍与镜头一一绑定，也不要把总时长机械地平分。
- 第一镜从 0 秒开始。上一镜结束时刻等于下一镜开始时刻。最后一镜止于目标时长。逐镜核对区间为正、连续、无重叠，时长总和与目标一致。
- 在确认前调整对白和镜头切点，让动作、停顿与转场在分配的时长内完成。确认后原样编译镜头数和时间；发现冲突时回到文字分镜，请用户确认修改。
- 实际视频工具若无法一次覆盖已确认的时长，保留总时长与逐镜结构。需要分次生成时按已确认的切点组织，不擅自改成工具的预设时长。

最终每个镜头输出一个段落，标题使用实际起止时间和「四字小标题・四字小标题」，段末使用：

```text
【光影色调：[本镜色调]｜画面风格：[本镜风格属性]】
```

## 4. 整体视听与一致性

- 画质：明确清晰度、题材美术、材质细节、人物肤质和商业成片质感。
- 光影：按画风和剧情安排色调。情绪需要变化时，把光影转折落到对应镜头；画风要求统一时保持一致。
- 转场：用动作、视线、遮挡或光线变化衔接。运镜服务于剧情信息，避免频繁碎切或复杂调度。
- 声音：音乐跟随剧情情绪，人声清晰，环境声贴合场景。允许留白。
- 连续性：保持人物面貌、发型、服装和人数一致；保持场景、道具、站位与光线连续；带货时保持产品外形、包装色、尺寸、标识位置与使用方式一致。

现代题材保留真实产品形态。古风、仙侠或年代题材只使用已确认的包装适配方案；品牌名称和标识必须真实，不新增包装文字。

## 5. 负面提示词

依次写通用基础项、2 至 4 项与当前题材相关的限制、带货禁用项、用户明确提供的禁止内容。用户明确要求某元素时，去掉与该要求冲突的通用项。

```text
不要字幕，不要 UI 标识，不要卡通化夸张特效，不要多余闲杂人物，不要浮夸夸张的肢体动作，不要面部崩坏变形，不要物品形态失真，不要多人同框复杂互动。
```

| 题材 | 针对性禁用内容 |
| --- | --- |
| 都市职场 | 不要古装或超自然能力，不要无因果升职致富，不要复杂会议群戏 |
| 豪门身份 | 不要靠价格证明人物价值，不要新增家族成员，不要无铺垫改变身份 |
| 重生穿越 | 不要多时间线反复切换，不要两个相同主角，不要复杂时空特效 |
| 古装权谋 | 不要现代建筑、服装或电子设备，不要虚构朝代文字，不要大规模宫斗群戏 |
| 仙侠玄幻 | 不要游戏界面，不要法术遮挡人物和产品，不要把产品表现成治病复活的神物 |
| 情感家庭 | 不要无铺垫暴力羞辱，不要用产品替代沟通，不要突然增加亲属 |
| 悬疑反转 | 不要血腥畸变，不要凭空出现证据，不要虚构监控或鉴定功能 |
| 青春成长 | 不要危险校园冲突，不要成人化权谋，不要生成校名、校徽或成绩保证 |
| 年代创业 | 不要时代错位物件，不要凭空暴富，不要虚构年代标语 |
| 热血传奇 | 不要群体打斗、爆炸或危险特技，不要复杂赛制和多人调度 |

带货时禁止在未安排露出的镜头突出产品名称或品牌标识，不要浮夸逆袭打脸或赛场领奖类反转。

## 6. 最终模板

替换所有占位符。只保留适用的模式模块，按已确认分镜逐镜重复时间段，不重复模板说明。

```text
【视频规格】
[总时长]秒，[画幅]，[语言]微短剧，[题材与画风]。

【整体画质与美术风格】
[清晰度、美术方向、材质细节、人物肤质和成片质感。]

【光影与色调】
[整体光影与色调。如有变化，写明发生变化的镜头及其目标色调。]

【运镜与转场的整体要求】
[与分镜匹配的运镜及转场方式。]

【声音规范】
[人声、环境声、音乐和需要保留的留白。]

[仅带货模式保留此模块]
【植入要求】
[按已确认镜头写产品如何参与剧情、何时展示标识，以及有固定口播时的实际位置和原文。]

【整体生成质量要求】
[保持人物、场景、道具连续一致，避免穿帮、换脸、错手、穿模、物品失真和动作断裂；带货时也保持产品一致。]

[按已确认分镜逐镜重复以下时间段块]
[起点]-[终点]秒｜[四字小标题]・[四字小标题]
[画面、运镜、动作、台词、环境音和背景音乐。]【光影色调：[本镜色调]｜画面风格：[本镜风格属性]】

【硬性执行规则】
总时长[总时长]秒，遵循以上镜头顺序和起止时间。动作和对白须在对应镜头内完整完成，画面连续。每镜末尾注明光影色调和画面风格。[带货模式追加：沿用已确认的产品外观；如有固定口播，逐字沿用已确认原文。]

【负面提示词】
[通用基础项、题材针对项、适用的带货禁用项和用户禁止内容。]
```
